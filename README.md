# Minimal To-Do List Application

Простое и минималистичное веб-приложение для управления повседневными задачами, созданное с помощью AI-инструментов в рамках тестового задания.

## 🚀 Демо
- **Live Demo:** [Посмотреть сайт](https://Romchanka.github.io/todo-app/)

## ✨ Функционал
- ➕ Добавление новых задач (по кнопке «Добавить» или клавише `Enter`)
- ✅ Отметка выполненных задач (клик по чекбоксу или тексту задачи с зачеркиванием)
- ❌ Удаление задач (кнопка с крестиком справа от задачи)
- 💾 Автоматическое сохранение состояния в `localStorage` (данные не теряются при перезагрузке страницы `F5`)
- 🔍 Фильтрация задач (Все / Активные / Выполненные) и быстрая очистка завершённых
- 📱 Адаптивный дизайн и тёмная тема (Glassmorphism UI)

## 🏗 Архитектурные решения и безопасность
- **Layered Clean Architecture (Repository → Store → View):**
  - `TodoStorageRepository` — изолированный слой работы с `localStorage`, устойчивый к ошибкам парсинга JSON и переполнению квоты хранилища (`QuotaExceededError`).
  - `TodoStore` — реактивное хранилище состояния (Single Source of Truth) с подпиской (`Observer pattern`).
  - `TodoView` — слой отображения с делегированием событий (`Event Delegation`) и пакетным обновлением DOM через `DocumentFragment`.
- **Защита от уязвимостей (XSS & Prototype Pollution):**
  - Исключено использование небезопасных `innerHTML` / `outerHTML`. Все узлы создаются через `document.createElement`, а пользовательский текст вставляется исключительно через `textContent`.
  - Внедрена строгая политика `Content-Security-Policy` (CSP).
  - Данные из `localStorage` проходят валидацию схемы и фильтрацию опасных ключей (`__proto__`, `constructor`, `prototype`) с использованием `Object.create(null)`.

## 🛠 Технологии
- HTML5 / CSS3 (CSS Variables, Flexbox, Backdrop Filter Glassmorphism)
- Pure JavaScript (ES6+, LocalStorage API, DOM API)
